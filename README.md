# DFA Simulator and Visualizer

An interactive Python-based desktop application developed as a mini-project for **Automata Theory and Computability (ATC)**. The application simulates Deterministic Finite Automata (DFA), visualizes state transition diagrams, and demonstrates how input strings are accepted or rejected.

## 📌 Project Overview

Understanding Deterministic Finite Automata can be challenging when studying only theoretical state diagrams and transition tables.

This project provides an interactive environment where users can select predefined DFA models, enter binary strings, and observe the behavior of the automaton.

The application displays state diagrams, transition tables, and simulation results to help students understand the fundamental concepts of DFA and regular languages.

## 🎯 Objectives

- To understand the working of Deterministic Finite Automata.
- To simulate DFA using Python.
- To visualize state transitions graphically.
- To determine whether a given input string is accepted or rejected.
- To display transition tables and execution traces.
- To provide an interactive learning tool for ATC students.

## ✨ Features

- Interactive graphical user interface.
- Multiple predefined DFA models.
- Graphical state transition diagrams.
- Transition table visualization.
- Binary string input and simulation.
- Acceptance and rejection detection.
- State transition execution trace.
- Initial state and final state visualization.
- Graphviz integration for diagram generation.
